# Space Trading Sim

A mobile-compatible browser strategy game about asteroid industry, shipping,
settlements, and piracy. Built around Next.js, Tailwind CSS, and TypeScript, with
browser-owned simulation and peer-to-peer multiplayer.

The project contains specifications and an interactive browser design study.
Start with the [specification index](docs/spec/README.md), or download the
[playable map study](docs/design/round-02/playable-study.html) and open it in a browser.
Its [source and run instructions](prototypes/map-play/README.md) describe the
prototype's scope and the Next.js entry point.
