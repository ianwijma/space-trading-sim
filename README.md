# Space Trading Sim

A mobile-compatible browser strategy game about asteroid industry, shipping,
settlements, and piracy. Built around Next.js, Tailwind CSS, and TypeScript, with
browser-owned simulation and peer-to-peer multiplayer.

The project is currently in specification. Start with the
[specification index](docs/spec/README.md).

Useful entry points:

- [Game vision and scope](docs/spec/vision-and-scope.md)
- [Scoring and victory](docs/spec/scoring-and-victory.md)
- [Housing and workers](docs/spec/housing-and-workers.md)
- [Population growth](docs/spec/population-growth.md)
- [Shipbuilding and crews](docs/spec/shipbuilding-and-crews.md)
- [Buildings and production](docs/spec/buildings-and-production.md)
- [Resource-flow insights](docs/spec/economy-insights.md)

requirements, proposed rules, and unresolved decisions are identified separately.
