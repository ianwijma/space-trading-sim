# Visual design studies

Status: visual exploration. The game targets mobile browsers first and adapts to
desktop. The user has requested a fantasy-space atmosphere inspired by Star Trek,
Star Wars, and related space adventures. A final visual direction is not selected.

## Current round

[Round 02: command a living map](round-02/README.md) is the current study. Download
its [interactive HTML](round-02/playable-study.html) and open it directly in a browser.
It supports camera controls, live traffic, ship orders, construction and crew boarding.

The user found the first boards too static. Round 02 makes the live map and direct
commands the main experience; its larger panels appear only when requested.

## Design priorities

- The asteroid map is the main play surface, with readable trade and fleet activity.
- Touch controls and information hierarchy are designed for a phone first.
- Population, housing capacity, building workers, and embarked crew remain distinct.
- Construction and launches preview their effect on the local economy.
- The atmosphere comes from original ships, settlements, material treatments,
  restrained celestial detail, and faction symbols.
- Desktop can use additional space for a selected-object inspector and optional reports.
- Each round preserves its images and records the feedback that informs the next.

The [interface specification](../spec/interface-and-art-direction.md) owns the
product requirements. This directory owns visual studies and iteration notes.
